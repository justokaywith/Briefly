# Briefly for Windows

Meeting audio capture and notes, connected to your Pactuno account.

## Windows preview

[Download version1.3.2](https://github.com/justokaywith/Briefly/releases/download/v1.3.2/Briefly-Setup-1.3.2.exe)

- Native Windows interface and browser-based Pactuno sign-in; no manual pairing token.
- Local microphone/system audio capture and local speech models.
- Live Listen is optional and asks before recording detected meetings.
- Saved transcripts and notes sync to your account. Review transcripts and email drafts before sharing.
- Setup preserves user-profile recordings, settings and saved sign-in.

This is an unsigned development preview. Supported-call, audio-device and screen-size acceptance is ongoing. Detection and transcription can be imperfect. Tell participants before recording and follow applicable consent requirements.
