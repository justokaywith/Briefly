# Briefly 1.3.7 candidate

This candidate repairs Live Listen evidence handling and installer completion. It does not claim all planned meeting features are complete.

- Read-only microphone-use records must match a live executable/package and its current process lifetime. Crashed-then-reopened apps cannot reuse stale activity as a new meeting signal.
- Live Listen preference and per-app ignore choices persist. Start, Ignore and Don't ask for this app are explicit; closing a prompt does not start capture.
- Supported UI Automation call controls remain a fallback for silent/muted calls. Registry metadata and English controls are not universal meeting detection APIs.
- Local Diagnostics records bounded fixed step codes, excluding transcript, title, email, paths and credentials.
- Successful setup closes automatically. The Open Briefly checkbox is respected; an unchecked option does not launch the app. App launch happens after setup closes. Existing running Briefly must first be closed safely, never force-killed by setup.
- App/setup/manifest/shortcut icon versions are consistently1.3.7. Current wave-logo branding and green animated setup splash remain.

Automated and isolated package checks cover native logic, prompt/keyboard safety, settings/layout, installer completion, staged preserving upgrade, package hashes, icon rendering and executable metadata. The owner installed the preceding 1.3.6 candidate and reported the Teams solo-call popup, recording and sync passed. The 1.3.7 changes after that acceptance unify popup presentation; no capture, speech or sync engine changes were made. This is not a universal device/accuracy claim.

Known limitations retained: Windows-only preview; mic/system capture currently lacks automatic device rebind and segmented crash recovery. Speech still uses the installed local tiny/small model on mixed audio, not separate-track timestamped transcription. Accuracy varies; review transcripts and notes. OS startup/tray residency, stronger optional models and subsequent client-memory/translation features are not completed by this release.

## Branded native dialogs

Alerts, recording/sign-out confirmations, meeting detection, rename, speech settings, Diagnostics, setup errors and uninstall now use a shared green/cream Briefly surface with its wave logo, rounded buttons, wrapping text and working-area bounds. Safe negative defaults remain for recording stop and destructive actions. Popup gallery and editing-dialog fixtures cover presentation and keyboard defaults without recording or changing customer meetings.
